mantras/
=========

LaTeX source for a collection of mantras, suktas (hymns), and prayoga
(ritual-procedure) texts commonly recited in daily worship and rites. This
is the source used by `vedamantrabook*.tex` at the repo root — see the root
[README](../README.md) for how the books and format variants fit together.
Unlike `aranyakas/`, `ashtakas/`, and `kandas/`, this collection isn't one
continuous canonical text — it's a curated set of separately-used mantras
and suktas, each in its own file, assembled in reading order by
`mantras.tex` at the repo root.

root README's format table for what each suffix means.
